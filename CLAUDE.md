## Project

Next.js 14 + TypeScript + Tailwind CSS site for Ca-Ca Canin (dog waste removal, Laval & North Shore QC). Deployed on Cloudflare via `@opennextjs/cloudflare`.

- English: `/` (`app/page.tsx`)
- French: `/fr` (`app/fr/page.tsx`)
- Components: `components/`
- Deploy: `npm run deploy`
